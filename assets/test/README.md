# テストデータ（栃木県宇都宮市周辺の架空の1週間）

ブラウザで試すときと、スマホの「テストデータで試す」で使う位置の点の列です。
`node scripts/make-test-data.mjs` で作り直せます（決まった乱数を使うので、毎回同じデータになります）。

## 形

iPhone で取るものと同じ「点の列」です。完成した運転の一覧は入れません。

```json
{ "t": "2026-11-16T07:47:01+09:00", "lat": 36.5899, "lng": 139.9846, "speed": 3.2, "accuracy": 7, "activity": "automotive" }
```

| 項目 | 意味 |
|---|---|
| t | 時刻（日本時間、ISO 8601） |
| lat, lng | 緯度・経度 |
| speed | 速さ（m/s） |
| accuracy | 位置の誤差（m） |
| activity | 移動の種類（CoreMotion の代わり）：automotive / walking / stationary / unknown |

- 期間：2026-11-16（月）〜 11-22（日）
- 点の間隔：乗り物は5秒ごと（止まっている間は15秒ごと）、歩きは10秒ごと、建物の中は10分ごと。夜（23時〜6時）は点がない。
- 電車とバスも、CoreMotion と同じく `automotive` になる（車との見分けは、アプリ側で線路との重なりと前後の徒歩で行う）。

## 場所（名前はすべて架空）

| 名前 | おおよその位置 |
|---|---|
| みどり台の家 | 宇都宮市の東、田畑の多いあたり |
| 駅東口のオフィス | 宇都宮駅の東口 |
| ひばりスーパー | 鬼怒通りの近く |
| 東部ショッピングモール | 駅と家の間 |
| みどり台バス停／駅東口バス停 | 家の近く／駅の東口 |
| 中央駅・南の駅（JR宇都宮線） | 線路の上の駅（名前は架空） |
| 南のカフェ | 南の駅の近く |

**注意**
- 道は手で決めた通過点を結んだだけで、実際の道路・線路に正確には沿いません。
  線路との重なりの判定を試す前に、OpenStreetMap の線路と比べて直してください。
- 家の点は、人の家に見えないよう田畑の多いあたりに置いています。使う前に地図で確かめてください。

## シナリオ

| | 内容 | 家で充電 | 状態 |
|---|---|---|---|
| A | 平日は車で通勤（約9km）。火・木は帰りにスーパー。月・水・金は昼に歩いて外へ。土曜はバスと電車で南の駅のカフェへ。日曜は車でショッピングモールとスーパー | できる | **できた**（`scenario-a.json`） |
| B | Aと同じ移動 | できない | ひな形（Aの点をそのまま使い、計算の条件だけ変える予定） |
| C | 平日はAと同じ。土曜に日光か那須へ車で遠出（片道50〜70km）。日曜に電車 | できる | メモのみ |
| D | 平日の夕方に駅へお迎え（10〜20分待つ）を週4回。待っている間は `stationary`。バスを1回 | できる | メモのみ |
| E | EVに乗っている人。外の充電スポット（架空）に30〜40分止まるのを週2回。電車を1回 | できる | メモのみ |
