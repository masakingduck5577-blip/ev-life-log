# テストデータ（栃木県宇都宮市周辺の架空の1週間）

ブラウザで試すときと、スマホの「テストデータで試す」で使う位置の点の列です。
`node scripts/make-test-data.mjs` で作り直せます（決まった乱数を使うので、毎回同じデータになります）。

## 形

iPhone で取るものと同じ「点の列」です。完成した運転の一覧は入れません。

```json
{ "t": "2026-11-16T07:47:01+09:00", "lat": 36.5899, "lng": 139.9846, "speed": 3.2, "accuracy": 7, "activity": "automotive" }
```

| 項目 | 意味 |
|---|---|
| t | 時刻（日本時間、ISO 8601） |
| lat, lng | 緯度・経度 |
| speed | 速さ（m/s） |
| accuracy | 位置の誤差（m） |
| activity | 移動の種類（CoreMotion の代わり）：automotive / walking / stationary / unknown |

- 期間：2026-11-16（月）〜 11-22（日）
- 点の間隔：乗り物は5秒ごと（止まっている間は15秒ごと）、歩きは10秒ごと、建物の中は10分ごと。夜（23時〜6時）は点がない。
- 電車とバスも、CoreMotion と同じく `automotive` になる（車との見分けは、アプリ側で線路との重なりと前後の徒歩で行う）。

## 場所（名前はすべて架空）

| 名前 | おおよその位置 |
|---|---|
| みどり台の家 | 宇都宮市の東、田畑の多いあたり |
| 駅東口のオフィス | 宇都宮駅の東口 |
| ひばりスーパー | 鬼怒通りの近く |
| 東部ショッピングモール | 駅と家の間 |
| みどり台バス停／駅東口バス停 | 家の近く／駅の東口 |
| 宇都宮駅・雀宮駅（JR宇都宮線） | OSM の駅の位置 |
| 南のカフェ | 雀宮駅の近く |
| ゆいの杜西・宇都宮駅東口（LRT） | OSM の停留場の位置 |
| 小山駅（新幹線） | OSM の駅の位置 |

**注意**
- 車の道は手で決めた通過点を結んだだけで、実際の道路に正確には沿いません。
- 電車（JR宇都宮線）・LRT・新幹線・高速道路（日光宇都宮道路）は、`assets/geo/` の OSM のデータ
  （© OpenStreetMap contributors, ODbL）の線路と道路の上をたどって作っています。
- 家の点は、人の家に見えないよう田畑の多いあたりに置いています。使う前に地図で確かめてください。

## シナリオ

| | 内容 | 家で充電 | データ |
|---|---|---|---|
| A | 平日は車で通勤（約9km）。火・木は帰りにスーパー。月・水・金は昼に歩いて外へ。土曜はバスとJR宇都宮線で雀宮のカフェへ。日曜は車でショッピングモールとスーパー | できる | `scenario-a.json` |
| B | Aと同じ移動 | できない | Aと同じ点（計算の条件だけ変える） |
| C | 平日はAと同じ（水曜にスーパー）。土曜に車で日光へ（片道約50km、日光宇都宮道路を通る）。日曜はバスとJR宇都宮線 | できる | `scenario-c.json` |
| D | 夕方に駅へお迎え（車の中で10〜20分待つ）を週5回。水曜はバスで通勤。土曜の昼は LRT で宇都宮駅東口へ（鬼怒通りの区間を通る） | できる | `scenario-d.json` |
| E | EVに乗っている人。金曜の帰りに充電スポットで20〜25分（急速）。土曜はバスと新幹線で小山へ | できる | `scenario-e.json` |

- E で止まる充電スポット（ENEOS アニマート柳田SS）は、Web版シミュレーターの公式一覧にある実在の公開スポットです。
- バスは見分けず、時速40km以上が30秒以上続かないので「車ではない」と判断されます。
